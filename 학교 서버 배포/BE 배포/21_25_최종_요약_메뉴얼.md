# Toolnet.Be 배포 매뉴얼 21~25

## 21~25. 최종 요약

### 21. 문제 원인

이번 문제의 핵심 원인은 DB 파일 마운트 상태였다.

```text
DB 구조 변경 때문에 Grape.db를 삭제함
docker-compose.yml에서 ./Grape.db:/app/Grape.db 파일 마운트를 사용 중이었음
삭제된 상태에서 Docker가 Grape.db를 잘못된 형태로 생성할 수 있음
SQLite가 Grape.db를 DB 파일로 열지 못함
FastAPI startup 실패
backend 컨테이너가 계속 Restarting 상태가 됨
```

### 22. 핵심 에러

```text
sqlite3.OperationalError: unable to open database file
```

이 에러는 SQLite가 지정된 DB 파일을 열 수 없다는 뜻이다.

### 23. 핵심 해결 명령어

```bash
sudo docker-compose down
sudo rm -rf Grape.db
touch Grape.db
sudo docker-compose up -d --build
```

### 24. 배포 후 확인 명령어

```bash
sudo docker ps
sudo docker logs toolnet-be-dev
sudo docker-compose logs --tail=100 backend
```

### 25. 한 줄 정리

`Grape.db`를 삭제한 뒤 Docker가 파일 마운트 경로를 제대로 잡지 못해 SQLite가 DB를 열 수 없었고, 잘못 생성된 `Grape.db`를 삭제한 뒤 빈 파일로 다시 만들어 컨테이너를 재실행해서 해결했다.
