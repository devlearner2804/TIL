# Toolnet.Be 배포 매뉴얼 66~70

## 66~70. 배포 전 체크리스트

### 66. develop 최신화 확인

배포 전에는 반드시 `develop` 최신 변경사항을 받아온다.

```bash
git checkout develop
git pull origin develop
```

작업 브랜치가 있다면 `develop` 최신 내용을 반영한다.

```bash
git checkout feature/backend-deploy-manual
git merge develop
```

### 67. 변경사항 확인

배포에 포함될 변경사항을 확인한다.

```bash
git status
git log --oneline -5
```

현재 브랜치를 확인한다.

```bash
git branch
```

원격 브랜치와 차이가 있는지 확인한다.

```bash
git fetch origin
git status
```

### 68. Dockerfile 확인

Dockerfile이 변경되었다면 다음을 확인한다.

```text
1. Python 버전이 팀 기준과 맞는가
2. requirements.txt 설치가 정상인가
3. WORKDIR이 /app 기준인가
4. main.py와 app 경로가 맞는가
5. uvicorn 포트가 docker-compose.yml과 맞는가
```

빌드 확인:

```bash
sudo docker build -t toolnetbe_backend .
```

### 69. docker-compose.yml 확인

Compose 파일에서 다음을 확인한다.

```text
1. backend 서비스 이름
2. container_name
3. ports
4. env_file
5. volumes
6. depends_on
7. restart
8. redis 서비스 이름
```

설정 파일 문법을 확인한다.

```bash
sudo docker-compose config
```

### 70. `.env` 확인

서버에 `.env`가 있는지 확인한다.

```bash
ls -l .env
```

내용을 확인한다.

```bash
cat .env
```

SECRET 값이 있다면 외부에 노출하지 않는다.

필수 값 예시:

```env
DB_NAME=Grape.db
REDIS_HOST=redis
REDIS_PORT=6379
REDIS_DB=0
```
