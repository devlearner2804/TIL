# Toolnet.Be 배포 매뉴얼 1~5

## 1~5. 배포 전 상태 확인

### 1. 프로젝트 폴더로 이동

백엔드 프로젝트가 있는 서버 폴더로 이동한다.

```bash
cd /path/to/toolnet-be
```

### 2. 현재 파일 목록 확인

현재 폴더에 필요한 배포 파일이 있는지 확인한다.

```bash
ls
```

예상되는 주요 파일은 다음과 같다.

```text
Dockerfile
README.md
docker-compose.yml
main.py
requirements.txt
.env
Grape.db
```

### 3. `.env` 파일 확인

DB 파일명이 올바르게 설정되어 있는지 확인한다.

```bash
cat .env
```

예시:

```env
DB_NAME=Grape.db

REDIS_HOST=redis
REDIS_PORT=6379
REDIS_DB=0
```

`DB_NAME=Grape.db`로 되어 있으면 FastAPI 앱은 실행 시 `Grape.db` 파일을 SQLite DB로 사용한다.

### 4. `docker-compose.yml` 파일 확인

Docker Compose 설정에서 DB 파일 마운트가 어떻게 되어 있는지 확인한다.

```bash
cat docker-compose.yml
```

확인해야 할 부분:

```yaml
volumes:
  - ./Grape.db:/app/Grape.db
```

이 설정은 서버의 `./Grape.db` 파일을 컨테이너 내부의 `/app/Grape.db` 파일로 연결한다는 뜻이다.

### 5. `Grape.db` 존재 여부 확인

`Grape.db`가 파일로 존재하는지 확인한다.

```bash
ls -l Grape.db
```

정상이라면 일반 파일 형태로 보여야 한다.

```text
-rw-r--r-- 1 user user 0 Jul  9 12:00 Grape.db
```

만약 `Grape.db`가 없거나 디렉터리로 생성되어 있다면 SQLite가 DB 파일로 열지 못할 수 있다.
