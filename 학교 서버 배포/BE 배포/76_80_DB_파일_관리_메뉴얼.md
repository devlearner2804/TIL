# Toolnet.Be 배포 매뉴얼 76~80

## 76~80. DB 파일 관리

### 76. SQLite DB 파일 확인

현재 프로젝트는 SQLite DB 파일로 `Grape.db`를 사용한다.

DB 파일 존재 여부를 확인한다.

```bash
ls -l Grape.db
```

파일이 없으면 Docker Compose 파일 마운트에서 문제가 생길 수 있다.

### 77. DB 삭제 전 백업

운영 데이터가 들어 있을 수 있으므로 삭제 전 백업한다.

```bash
cp Grape.db Grape.db.backup
```

날짜를 붙여 백업하려면 다음처럼 한다.

```bash
cp Grape.db Grape.db.backup.$(date +%Y%m%d_%H%M%S)
```

백업 파일 확인:

```bash
ls -l Grape.db.backup*
```

### 78. DB 삭제

DB 구조 변경으로 기존 DB를 삭제해야 한다면 컨테이너를 먼저 내린다.

```bash
sudo docker-compose down
```

이후 DB 파일을 삭제한다.

```bash
sudo rm -rf Grape.db
```

### 79. 빈 DB 파일 재생성

Docker Compose에서 파일 마운트를 사용하므로 빈 파일을 다시 만든다.

```bash
touch Grape.db
```

파일 형태를 확인한다.

```bash
ls -l Grape.db
```

정상 예시:

```text
-rw-r--r-- 1 user user 0 Jul  9 12:00 Grape.db
```

### 80. DB 관련 오류 확인

컨테이너 실행 후 로그를 확인한다.

```bash
sudo docker-compose up -d --build
sudo docker-compose logs --tail=100 backend
```

다음 오류가 없어야 한다.

```text
sqlite3.OperationalError: unable to open database file
```
