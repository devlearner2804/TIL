# Toolnet.Be 배포 매뉴얼 71~75

## 71~75. 서버 배포 명령어

### 71. 서버 접속

서버에 SSH로 접속한다.

```bash
ssh user@server-ip
```

예시:

```bash
ssh ubuntu@123.123.123.123
```

서버 접속 계정과 IP는 팀원에게 확인한다.

### 72. 프로젝트 폴더 이동

백엔드 프로젝트 폴더로 이동한다.

```bash
cd /path/to/toolnet-be
```

현재 위치를 확인한다.

```bash
pwd
```

파일 목록을 확인한다.

```bash
ls
```

### 73. 서버 코드 최신화

배포 브랜치가 `develop`이라면 다음처럼 최신화한다.

```bash
git checkout develop
git pull origin develop
```

배포 브랜치가 `main`이라면 다음처럼 한다.

```bash
git checkout main
git pull origin main
```

어느 브랜치를 배포하는지는 반드시 팀원에게 확인한다.

### 74. 컨테이너 재시작

기존 컨테이너를 내린다.

```bash
sudo docker-compose down
```

다시 빌드하고 실행한다.

```bash
sudo docker-compose up -d --build
```

### 75. 배포 결과 확인

컨테이너 상태를 확인한다.

```bash
sudo docker ps
```

backend 로그를 확인한다.

```bash
sudo docker logs toolnet-be-dev
```

또는:

```bash
sudo docker-compose logs --tail=100 backend
```
