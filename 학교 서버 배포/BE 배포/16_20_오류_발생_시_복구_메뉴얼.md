# Toolnet.Be 배포 매뉴얼 16~20

## 16~20. 오류 발생 시 복구 절차

### 16. backend가 계속 재시작되는지 확인

컨테이너가 계속 죽고 다시 시작되는지 확인한다.

```bash
sudo docker ps
```

다음처럼 보이면 앱 실행 중 오류가 발생한 것이다.

```text
toolnet-be-dev   Restarting (3)
```

### 17. 로그에서 원인 확인

컨테이너 로그를 확인한다.

```bash
sudo docker logs toolnet-be-dev
```

DB 파일 문제가 있으면 다음 오류가 보일 수 있다.

```text
sqlite3.OperationalError: unable to open database file
```

### 18. 컨테이너 종료

문제 해결을 위해 컨테이너를 내린다.

```bash
sudo docker-compose down
```

### 19. 잘못 생성된 DB 경로 삭제 후 재생성

`Grape.db`가 파일이든 폴더든 확실히 삭제한 뒤 빈 파일로 다시 만든다.

```bash
sudo rm -rf Grape.db
touch Grape.db
```

### 20. 다시 배포

Docker Compose를 다시 실행한다.

```bash
sudo docker-compose up -d --build
```
