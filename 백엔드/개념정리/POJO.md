# POJO


## POJO란? 

POJO는 Plain Old Java Object의 약자로, 특정 프레임워크나 기술에 종속되지 않는 순수한 Java 객체를 의미한다.

POJO는 Spring과 같은 프레임워크를 사용하지 않는다는 의미가 아니라, 객체의 핵심 기능이 특정 프레임 워크에 강하게 의존하지 않도록 만드는 것이 중요하다.

예를 들어 다음과 같이 Java의 기본 기능만으로 만든 객체는 특정 프레임워크가 없어도 사용할 수 있다. 
```
public class User {
    private String name;
     
    public void changeName(String name) { 
        this.name = name; 
    } 
}
```

이러한 방식으로 객체를 만들면 특정 기술이나 환경이 변경되더라도 핵심 코드를 재사용하거나 수정하기 쉬워진다.

## POJO 사용 이유

POJO는 특정 기술이나 프레임워크에 강하게 종속되지 않기 때문에 재사용성과 유지보수성을 높일 수 있다.

특정 기술이 변경되더라도 핵심 로직을 크게 수정하지 않고 사용할 수 있으며, 특정 환경에 의존하지 않기 때문에 테스트하기도 쉽다.

또한 특정 프레임워크의 규칙에 제한받지 않고 객체지향적인 설계를 적용하기 쉽다는 장점이 있다.
